# Report format

Every final report has exactly these sections, in this order:

1. **Recommendation** — one sentence: "Choose X because Y."
2. **Why** — 3 bullets, each under 20 words
3. **Comparison at a glance** — a small table (max 5 rows)
4. **Watch out for** — 2 bullets on risks or trade-offs
5. **Sources** — list of links used

Rules:
- Under 300 words total
- No jargon; write for a non-technical manager
- Prices must include the date checked, e.g. "$10/user/mo (checked Nov 2026)"
