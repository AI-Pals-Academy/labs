# Project instructions – Family Recipe Binder

Copy everything between the lines into: Context tab → Instructions → Project instructions → Save changes.

---

THREADS
- One thread per recipe, named "Recipe – <dish>".
- Do the recipe work inside its thread, not in the main chat.
- Before starting a new thread, check for an existing thread on the
  same dish (including resolved ones). If one exists, ask me:
  "Continue the old thread, or start a fresh one?"

ARTIFACTS
- Each recipe gets one doc, titled "Recipe – <dish>".
- When I come back to a recipe, update that same doc.
- Keep a short "Changes" list at the bottom with the date of each update.

INDEX
- Keep a recipe index in project memory: dish, thread name, doc name,
  date last updated. Check it before starting any new recipe thread.

---

# Blank template for your own project

Replace the <...> parts, then paste it into your own project's instructions.

---

THREADS
- One thread per <item>, named "<Type> – <name>".
- Do the work for each <item> inside its own thread, not in the main chat.
- Before starting a new thread, check for an existing one on the same
  <item> (including resolved ones) and ask me first.

ARTIFACTS
- Each <item> gets one <doc / spreadsheet / deck>, titled "<Type> – <name>".
- Update the same artifact when I come back. Keep a dated "Changes" list.

INDEX
- Keep an index in project memory: <item>, thread name, artifact name,
  date last updated. Check it before starting any new thread.
