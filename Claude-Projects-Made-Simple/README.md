# WB02 · Claude Projects Made Simple

Plan, organize and automate any big piece of work with **Claude Projects**: one project, one main chat, a separate thread for each task, and nothing lost.
You learn the ideas with simple pictures (a project is a binder), then build a real project step by step.

**The scenario:** you turn your family's scattered recipes into a **Family Recipe Binder** in Claude. Each recipe gets its own thread and its own recipe doc. You upload photos of handwritten recipe cards, let Claude spot recipes you already have, save a shopping list to Google Drive, print a recipe booklet, and finish with a weekly meal plan that Claude writes for you every Sunday.

## Quick start

1. Download **`WB02-Claude-Projects-Made-Simple.pdf`** and **`recipe-binder-lab.zip`** (click the file, then the ↓ download button).
2. Unzip `recipe-binder-lab.zip`, for example into your *Documents* folder.
3. Open the Claude desktop app (**Code** tab) or go to **claude.ai/code**, and click **Projects** in the left sidebar (look under **More** if you don't see it).
4. Follow **Practice 0** in the PDF.

> **Tip:** the `.md` files are plain text. Open them with Notepad (Windows) or TextEdit (Mac) and copy the text you need.

## What you need

- A paid Claude plan (Pro or Max) with **Projects**. Projects is rolling out gradually, so it may not be on every account yet.
- Optional: Google Drive connected to Claude, for Practice 7
- About 2 hours for all practices (you can stop after any practice)

## What's inside the starter files

```
recipe-binder-lab/
├─ README.md                    ← what each file is for
├─ rules-template.md            ← project instructions to paste (Practice 2), plus a blank template
├─ moms-tacos-card.jpg          ← a handwritten card for a recipe you'll already have (Practice 5)
├─ dads-banana-bread-card.jpg   ← a handwritten card for a new recipe (Practice 5)
└─ prompts.md                   ← every "Type this" prompt in the workbook
```

The recipe cards are made-up examples drawn for this workbook.
